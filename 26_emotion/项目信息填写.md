# 项目信息填写

## 项目名称

**中文名称**：基于脑电基础模型与情感神经先验的跨被试情绪识别算法

**英文名称**：Cross-Subject EEG Emotion Recognition Based on EEG Foundation Model and Affective Neural Priors

---

## 项目中文简介

脑电情绪识别是情感计算与脑机接口领域的重要研究方向，其核心挑战在于不同个体间脑电信号模式差异显著，导致模型在跨被试场景下泛化能力不足。本项目面向跨被试脑电情绪二分类任务，提出一种融合预训练脑电基础模型表征与情感神经先验特征的双路提取与自适应融合框架。在特征提取阶段，一路利用在大规模多数据集上预训练的脑电基础模型提取高层时空语义表征，另一路基于情感神经科学研究成果构建先验特征，涵盖频域微分熵、脑区间功能不对称性等反映情绪加工神经机制的可解释指标。在特征融合阶段，设计基于注意力机制的跨模态融合模块，使数据驱动表征与神经先验特征实现互补增强。此外，针对训练数据中健康被试与抑郁症被试脑电模式存在系统性差异、而测试时被试身份未知的问题，引入自适应路由机制，使模型能够根据输入信号自动调整分类策略。实验结果表明，所提方法在跨被试验证协议下取得了良好的分类性能，验证了基础模型表征与情感神经先验融合在脑电情绪识别中的有效性。

## 项目英文简介

EEG-based emotion recognition is an important research direction in affective computing and brain-computer interfaces. A key challenge lies in the substantial inter-subject variability of EEG signal patterns, which limits the generalization capability of models in cross-subject scenarios.

This project addresses the cross-subject EEG emotion binary classification task and proposes a dual-path feature extraction and adaptive fusion framework that integrates representations from a pre-trained EEG foundation model with affective neural prior features. In the feature extraction stage, one path leverages an EEG foundation model pre-trained on large-scale multi-dataset corpora to capture high-level spatiotemporal semantic representations, while the other path constructs prior features grounded in affective neuroscience research, encompassing interpretable indicators that reflect the neural mechanisms of emotional processing, such as spectral differential entropy and inter-regional functional asymmetry. In the feature fusion stage, an attention-based cross-modal fusion module is designed to enable complementary enhancement between data-driven representations and neural prior features.

Furthermore, considering that the training data contains both healthy control (HC) and depression (DEP) subjects whose EEG patterns exhibit systematic differences, while subject identity is unavailable at test time, we introduce an adaptive routing mechanism that allows the model to automatically adjust its classification strategy based on the input signal characteristics.

Experimental results under a cross-subject evaluation protocol demonstrate that the proposed method achieves competitive classification performance, validating the effectiveness of integrating foundation model representations with affective neural priors for EEG-based emotion recognition.
